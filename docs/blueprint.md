# **App Name**: DocuFind

## Core Features:

- Role-Based Access: Restrict access to features and data based on user roles (reporter, finder, RC staff, police, admin).
- Document Reporting: Allow users to submit lost document reports with details and file uploads.
- Document Searching: Enable users to search for lost documents based on various criteria.
- Intelligent Matching Tool: Use AI to suggest potential matches between reported lost documents and found documents.
- Admin Dashboard: Provide an administrative interface for managing users, roles, and system settings.
- File Upload: Implement the ability to upload files (e.g., images or scanned documents) as part of document reports.
- Authentication: Secure the application with JWT-based authentication, managing user sessions, and protecting API endpoints.

## Style Guidelines:

- Primary color: (#731d03) to convey trust and reliability.
- Background color: color #15f211 for a clean, uncluttered look.
- Accent color:  #11d0f2 to highlight important actions and notifications.
- Body and headline font: 'PT Sans', a sans-serif, providing a modern and approachable feel suitable for both headlines and body text.
- Use simple, clear icons from a library like Font Awesome to represent actions and document types.
- Implement a clean, responsive layout using TailwindCSS grid and flexbox to adapt to different screen sizes.
- Use subtle animations, such as fades and transitions, to enhance user experience and provide visual feedback without being distracting.
